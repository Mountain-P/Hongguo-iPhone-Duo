# 紅果 · iPhone Duo

為 iPhone Duo 打造的原生紅果短劇 App。收合時隨手看，展開後自在選劇；從海報、演員到播放器，都使用適應螢幕的 SwiftUI 介面與系統控制列。

**目前版本：0.12.0／build 29（2026-11-08）。** 影片直接在 iPhone 取源、載入及播放，不需設定播放服務，也不必讓電腦持續開機。

本版依倍速提高目前影片的緩衝目標，加入最多 512 MiB 的磁碟分段快取，並在合適網路與電量條件下主動預讀目前這集。下一集預載需先有足夠的目前集餘裕；設定可查看快取用量及清除。仍採漸進起播，實際改善與驗證界線見 [驗證紀錄](docs/TESTING.md)。

0.11.1 為有效前後十秒、手動選速、長按加速及鎖速／解除加入一次觸覺回饋，不喚回控制列；取消、背景、換集及捏合清理保持安靜，硬體震感的驗收見 [驗證紀錄](docs/TESTING.md)。

0.11.0 讓試看「追這部」在條件吻合時直接沿用同一個 AVPlayer 與影片 item；一般播放器換集時保留舊的實際影格，直到新畫面與定位就緒。推薦新增「多推薦這類／少推薦這類」，只使用作品真實題材；新頁排序也參考目前片單最後兩部的題材，減少跨頁重複，保留正在看的卡片。試看另有頁內滿版與 0.5–3 倍畫面縮放。各項建置、GUI 與手機驗收狀態見 [驗證紀錄](docs/TESTING.md)。

0.9.3 起一般播放器支援上下滑換集：明確上滑播放緊鄰下一集，下滑播放緊鄰上一集，成功換集從零開始。短距離移動不換集；到第一／最後集或鄰集未開放時，保留當集並在頂部提示約 2 秒，不跳過未開放集，也不喚回整組控制列。長按後的上下滑優先處理鎖速，不換集；試看仍以上下滑換劇。

0.9.2 的獨立倍速提示持續保留：長按開始、放開，以及一般播放器的鎖定／解除鎖定都不再喚回整組控制列，只由獨立頂部倍速提示呈現，保留控制列原本的顯隱狀態。試看提示也獨立於 HUD 的隱藏效果；點空白處顯隱、中央播放／暫停及手動速度選單維持原有操作。

0.9.1 的試看換劇交接持續保留：滑到正在預取的下一部時，沿用尚未完成的詳情與取源請求，避免取消後重新等待；連續跳過多部則以最後停穩的作品為準。維持只播放當前卡片、既有預取及快取上限，並保留省電與網路限制。當時固定延遲對照確認減少重複等待，實網首幀仍受來源影響；量測與裝置結果依版本記於驗證紀錄。

0.9.0 擴充的同類榜單／近期新劇候選、來源標示及「追這部」原地重試持續保留。

0.8.0 加入的功能持續保留：

- 首頁與試看以目前片庫的收藏、合格保存位置及真實共同題材作本機排序，附上原因；保留探索，只排序新增片單，不移動正在看的卡片。
- 試看按「追這部」可從剛才的位置進入正式播放；若已有不同正式進度，先讓你選擇。點片名仍可進入詳情與選集。
- 點影片空白處改為顯示／隱藏控制列；播放與暫停使用中央按鈕，移除右上重複按鈕，長按倍速操作保留。

## 適應 Duo 的觀看方式

- 「首頁／試看／劇場／我的」四個原生分頁，隨螢幕姿態調整配置。海報網格依寬度改變欄數，完整顯示封面，自然垂直捲動。
- 一般全螢幕播放器使用真正的原生工具列：外螢幕與內螢幕橫向可採側邊配置，內螢幕直向使用上下列，位置由系統決定。
- 輕透明 Liquid Glass 資訊框呈現片名、集數與進度；控制列覆蓋影片，顯示或隱藏都不擠壓畫面。較舊系統使用相容材質。

首頁先讓你挑劇。點海報看詳情，按「開始觀看」才準備影片並進入獨立全螢幕播放器；最近觀看也可直接按「繼續觀看」。換看另一部劇時回到海報，由你決定何時開始。

## 上滑，試看下一部

「試看」是在同一頁連續上下捲動的影片卡片，每部劇佔滿一個可用畫面。拖曳時卡片跟著手指移動，鄰頁海報自然滑入；已播放的卡片暫停並保留最後影格，停穩且對齊後才允許當頁播放，滑動或慣性捲動中不啟播下一部。候選來自目前目錄，再依這部 iPhone 目前片庫的題材線索排序；沒有使用官方個人化推薦 API。

0.9.3 加入旋轉／尺寸變更後的重新對齊：保留最後停穩的作品，待新畫面對齊後才恢復播放資格與互動，過渡期間避免誤點。原片單、已載入資料及手動暫停意圖保留；修後畫面驗收另見 [驗證紀錄](docs/TESTING.md)。

首次選中的劇從第 1 集零秒試播，播完暫停；試看不寫觀看紀錄、不覆蓋原本續播位置。按「追這部」會擷取當下集數與秒數，核對最新詳情後進入正式播放；若已有不同的正式進度，可選「接續原進度」或「從試看位置看」。點片名則沿原生導覽進入詳情與選集。返回保留原卡片與捲動位置，等待手動「繼續試看」。試看長按只提供暫時 2 倍速，上下滑留給換劇。首頁與劇場仍由你按「開始觀看」才載入影片。

本機排序以收藏作較強訊號，最近紀錄中至少 30 秒且到達半集的保存位置作較弱線索，只使用來源實際提供的共同題材，不從片名猜測、不把自動試看曝光當喜歡。帳號、本機片庫與來源分開，沒有有效線索時沿用來源順序；收藏或進度更新只影響新批片單與可顯示的理由，正在看的卡片保留。細節見 [本機推薦排序](docs/DISCOVERY.md#本機推薦排序)。

試看頁可直接收藏，也能從選項開啟「推薦偏好」，選擇真人／漫劇／AI 短劇、略過已試看的劇，或將當前劇標為「不感興趣」。在偏好頁可重新顯示試看過的劇、恢復隱藏推薦；「我的 → 設定 → 推薦偏好」也能調整。這些偏好只保存在這部 iPhone，不會改動官方帳號推薦。「已試看」是獨立的本機標記，不是觀看進度，正在看的卡片不會因剛被標記而消失。通常累計有效播放 10 秒才標記，短片採片長九成、最低 1 秒；暫停、緩衝、背景或滑動期間不累計，倍速與拖曳進度不會加快計時。

「多推薦這類／少推薦這類」只列出作品實際提供的有效題材，用來提高或降低新候選的排序，少推薦不等於隱藏整類。每個片庫、來源與內容類型各自保存，最多 32 個題材；可逐筆或全部恢復中性。不會從單劇「不感興趣」自動推斷題材偏好，也不提交官方個人化 API。

試看可在頁內進入滿版，隱藏原生分頁列、狀態列與控制資訊；點空白處只切換控制，不直接播放或暫停。雙指縮放範圍為 0.5–3 倍，選單也提供放大、縮小、還原及完整比例／填滿切換，上下滑仍換劇。

0.10.0 加入重新開啟 App 後回到上次試看的作品與第一集位置。這份短期記憶依片庫、來源及內容類型隔離，與正式觀看歷史分開；重新取得最新分集後才使用保存位置。當版以一張暫存畫面銜接正式播放器。0.11.0 進一步在同劇同集、位置誤差不超過 2 秒、片庫／來源 revision／畫質一致、前景有效且未滿 60 秒時重用原播放器與 item；不符合就沿用正常準備流程，保留最新詳情與進度檢查。

## 順手看劇

系統 AVPlayer 支援填滿螢幕與完整比例切換、選集、前後十秒、倍速、斷點續播及同劇自動下一集。上下滑時顯示目標集數與切換門檻，拉回或短滑可取消；進度條拖動時顯示放大時間，手指往上移可切換 ½、¼、¹⁄₁₀ 速度細調，放開才定位。影片採漸進載入，索引準備好就能開始，播放與拖曳時再按需取得資料。

「我的 → 設定 → 畫質與流量」可保存內建播放的來源偏好。「自動（最佳可用）」沿用原本選源策略；「省流量」優先選來源中尺寸可確認的較低畫質相容版本，沒有較低版本時仍使用可播放來源。這是 MP4 來源選擇，不是隨網路動態調整的 ABR，也不會即時切換正在播放的影片；自訂服務不套用此設定。

停在已播完的分集時，再按播放會先回到開頭重播。手動選定的倍速與「自動播放下一集」開關會保存在本機；暫時長按和鎖速手勢不改寫保存的速度，試看仍只播第一集。正式播放在接近片尾、緩衝充足且自動下一集開啟時，可受限準備下一個可用集的首段；僅限內建播放與符合網路／電力政策時進行，暫停、背景化或離開時取消，不另建立播放器或下載整集。

0.6.1 在片尾清除已結束的播放意圖，讓暫停／重播控制保持一致；音訊中斷或耳機移除事件會暫停，中斷結束不自行恢復。真耳機拔除與來電仍待實機驗證。

以下倍速鎖定操作適用一般全螢幕播放器；同頁試看不提供上下滑鎖定，以保留連續換劇手勢。

一般播放器在未進入長按時，明確的垂直滑動會切換同一部劇的緊鄰分集；長按成立後，上下滑優先鎖定／解除倍速，不觸發換集。

長按、放開及鎖定／解除只更新獨立倍速提示，不改控制列的顯隱；手動開啟速度選單仍維持原有行為。

| 操作 | 效果 |
| --- | --- |
| 點影片空白處 | 顯示／隱藏控制列，維持當前播放狀態 |
| 點中央播放／暫停圖示 | 暫停／繼續 |
| 一般播放器明確上滑／下滑 | 下一集／上一集，成功切換從零播放；邊界或未開放時只提示 |
| 試看上下滑 | 下一部／上一部劇 |
| 長按 0.35 秒 | 暫時 2 倍速，放開恢復原選速度 |
| 長按後上滑 60 pt | 鎖定 2 倍速 |
| 鎖定後再長按、下滑 60 pt | 解除鎖定，恢復原選速度 |
| 點鎖定提示或從選單選速度 | 解除倍速鎖定 |

## 從想看的劇開始

劇場整合搜尋、推薦、四種熱播排行榜、真人／AI 近期上新，以及真人／漫劇／AI 分類與來源提供的題材。劇集詳情可看簡介、分集、演員與角色、評分、熱度及上架資訊；點演員查看參演作品，也能接著逛相似推薦。

搜尋先用原關鍵字；只有完整空結果且沒有更多頁時，才補查一次簡繁字形並顯示提示。可依來源標籤篩選已載入結果的題材，刪除單筆或清空搜尋歷史；不把題材標籤猜成真人／漫劇／AI 的全站分類。

目錄下拉更新會隔離舊回覆；遇到來源仍有更多頁的空白或重複頁，保留繼續載入入口，避免漏掉後面的作品。

長劇選集每 30 集分組，可輸入集數按「跳至」，或按「上次第 n 集」快速定位。定位只切換顯示範圍並標出分集，點分集才播放；尚未開放的集數仍保持鎖定。

片單與顯示資訊取自來源；資料缺少時仍可使用分集與播放。詳見 [選劇說明](docs/DISCOVERY.md)。

## 帳號與自己的片庫

「我的」提供原生手機驗證碼登入、收藏、觀看歷史、各集進度與同步狀態。號碼及驗證碼透過官方 HTTPS API 傳送，不經自建服務；登入會話保存在這部 iPhone 的 Keychain，與匿名影片播放分開。

本機片庫、各個帳號與播放來源分開保存。結果尚未確認的寫入會保留「需手動重試」狀態，重新啟動不會暗中重送，其他新變更仍可繼續同步。登入後可明確選擇匯入本機片庫；收藏與觀看變更先存手機，官方確認後才清除對應待同步操作，失敗時保留紀錄。使用方式與同步範圍見 [帳號與片庫](docs/ACCOUNT.md)。

「我的」可在目前收藏或歷史中進行本機搜尋、排序與多選管理；全選只選符合目前搜尋與篩選的結果。移除前會確認片庫與數量：觀看紀錄只從本機移除，帳號取消收藏則沿用待同步流程，兩者分開處理。

片庫搜尋在背景處理；從詳情返回時，只重用一份資料與完整條件都相同的已完成結果，待處理工作與其他帳號結果不共用。人工同步重試會輪替失敗項目，避免首批失敗擋住後面的變更；輪替順序只保留於當次 App 記憶體，跨啟動的「需手動重試」保護仍持續生效，不會自動重送這些項目。

歷史 0.4.2 已完成實機原生登入、更新後會話還原、雲端資料讀取，以及收藏新增／取消、播放後進度寫入的成功狀態；0.4.3 的模擬器檢查與無線安裝、0.4.4 的同頁連續試看驗證亦分版保留。0.5.0 加入本機推薦偏好、試看直接收藏與快速選集。0.6.0 的重播、預取、搜尋、片庫管理與診斷，分別以核心測試、當版畫面、合成連播及手機部署記錄核對，詳見 [驗證紀錄](docs/TESTING.md)。跨裝置獨立核對等範圍分開記錄；單次成功不代表所有帳號或地區都適用。

0.6.1 已通過核心／AppSupport 測試及模擬器、實機建置；當版 GUI、安裝與音訊事件的實際結果另依驗證紀錄，不以建置代替裝置操作。

## 本機播放診斷

「我的 → 設定 → 播放診斷」保留最近 80 次已結束測量，可看首幀等待（TTFF）、播放中等待與重試；另顯示目前資源狀態。原片重播使用已載入影片，只記定位準備，不混入首幀等待中位數。系統 MetricKit 日報另列整個 App 的記憶體、CPU 與捲動資料，不代表單次影片或本版效能；模擬器數值也不代表實機。

診斷資料只保存在本機，不外傳，不記錄片名、劇集 ID、播放網址、帳號或憑據；可清除播放測量而不影響片庫。這些工具用來蒐集後續量測，尚不代表已證實等待時間或耗電改善。

## 安裝到 iPhone

最低 iOS 17；本專案以 Xcode 27.2 建置並適配 Duo。

1. 在 Mac 安裝完整 Xcode 與 iOS SDK，開啟 `iOS/Hongguo.xcodeproj`。
2. 在 Hongguo target 的 Signing & Capabilities 選自己的 Apple 開發團隊，必要時修改 Bundle Identifier。
3. 接上 iPhone，完成信任與 Developer Mode 設定，選擇實機後按 Run。

未簽署 IPA 需要自行重新簽署；原始碼 ZIP 不能直接安裝。完整步驟見 [建置、簽署與側載](docs/BUILD.md)。進階使用者另可設定 [自有橋接服務](docs/BRIDGE.md)。
