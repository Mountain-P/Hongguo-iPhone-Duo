| 家中中繼，實際片庫兩集 | 第 1 集在播放位置 2.16 秒時阻斷媒體 6 秒，同一媒體恢復傳輸後繼續以 2× 解碼。下一集第一次請求回傳 503，播放器重試並採用了預讀片頭；自動換到第 2 集後 0.89 秒取得首幀。兩集均播完，各擷取 855 與 922 個實際解碼影格。 |

Swift 核心 657 項、AppSupport 112 項，以及 Node 後端 42 項通過。另修正一個在平行測試下會誤判的計時測試，讓測試能明確控制主來源與備援來源的先後順序。發行程式維持原有延遲策略。正式 App 原入口及隔離驗收入口都已建置為 arm64 iOS Simulator App。

家中中繼的數據是使用既有家中片庫的隔離實例，這次只更新功能分支。測試後已關閉模擬器與隔離服務。實際行動網路的延遲可能不同。

## 播放中的變更

- 手機直連與中繼的下一集預載會記錄成功或失敗。仍是同一個下一集、當集已緩衝到片尾，且網路與播放狀態允許時，暫時失敗可在 1 秒、3 秒後重試。切換集數或離開會取消準備。
- 中繼的下一集片頭可以預讀到手機。1× 預讀上限 512 KiB，2× 上限 1 MiB。播放器接手同一份來源時重用這段資料，後續讀取核對強 ETag、位移和總長度。
- 手機直連播放途中某段連線暫時中斷時，保留原來的 AVFoundation 讀取請求。需要同一分段的讀者共用一輪有限重試。只交付驗證完成的位元組，單一讀者取消不會中止其他讀者。授權拒絕、影片版本改變及使用者取消會中止對該段的重試。
- 暫停超過 30 秒後，由使用者按播放。若舊來源已失效，可更新一次同集來源，保留原位置和倍速。仍可播放的來源照常續播。
- 「播放診斷」列出播放方式及最近失敗的階段，包括取得來源、載入媒體、等待首幀或播放途中。現有使用者的舊紀錄仍可讀取。
- 離線劇卡可搜尋劇名並直接續看，優先選最近未看完的已下載分集，播完後可接下一個已下載分集。一般下載進度最多每秒更新四次，完成、失敗及取消即時顯示。

## 家中中繼的三個修正

1. 片庫檔案遺失或損壞時，自動檢查同集完整快取。需要回到來源時，先確認分集歸屬。快取本身損壞時也可恢復。舊版本媒體網址不會接上另一份檔案的位元組。
2. 取得播放來源時遵守選集清單的有效期，遇到剛新增的分集會合併更新後再核對。中繼確認分集不屬於該劇時，iPhone 顯示對應的選集提示。
3. 讀取影音分段時使用最近一次成功建立的索引。更新會在背景合併，媒體檔頭按需要檢查。147 個 4 KiB 測試檔、兩個並行分段讀取的對照中，修正後只有一次索引更新，開啟媒體檔兩次，兩個請求皆回應 HTTP 206。

## 測試方式

使用獨立的 iPhone Duo / iOS 27.2 模擬器套件與正式 PlayerScreen、PlayerModel、AVFoundation。每條路徑均以 2× 播放第一集至下一集，只有偵測到實際解碼畫面且第一集進度已超過 2 秒才觸發 6 秒的媒體斷線。驗收核對傳輸確實中斷、同一份媒體有新位元組、第一集恢復解碼、第二集顯示新影格，以及兩集皆自然播完。測試過程不操作實體 iPhone。

- 家中中繼使用同一台家中伺服器上的隔離實例，唯讀既有片庫，透過 SSH 轉送至模擬器。手機直連備援關閉。另將第二集第一次播放資料請求設為 HTTP 503，以檢查預載會再試。
- 手機直連分兩次測。正式片源使用內建 NativeCatalogService 按正常流程取得劇集；受控測試使用自製的兩段 H.264，測試用目錄及來源指向本機 HTTP 服務。受控測試沿用正式的分段回應檢查、快取、原生影音載入器、播放和換集。斷線由測試服務實際截斷傳輸。
- 兩個測試的完整播放器日誌與私有設定留在本機。專案內的測試入口和注入工具只用於隔離的模擬器建置。工具收尾會移除模擬器的中繼口令並關閉該模擬器。
- 另以 macOS AVPlayer 測試音軌長於影軌、影軌長於音軌，以及移除後 55% 的檔案。1× 與 2× 的四次正常播放都只觸發一次自然結束，兩次截斷檔均回傳 AVFoundation 錯誤且沒有自然結束。

可從專案根目錄執行以下命令。兩個播放測試應依序執行，避免模擬器共用宿主音訊裝置時打斷另一個播放器。中繼設定檔使用現有 QA 格式，包含 baseURL、token、seriesID。請存於 build 或其他未納入 Git 的私有路徑。

```sh
python3 scripts/playback-interruption-qa.py --device "$SIMULATOR_UDID" --output build/continuity-qa --case build
python3 scripts/playback-interruption-qa.py --device "$SIMULATOR_UDID" --output build/continuity-qa --case direct-fixture --ffmpeg "$FFMPEG_PATH"
python3 scripts/playback-interruption-qa.py --device "$SIMULATOR_UDID" --output build/continuity-qa --case relay --config "$RELAY_QA_CONFIG" --prefetch-fault
python3 scripts/playback-interruption-qa.py --device "$SIMULATOR_UDID" --output build/continuity-qa --case direct
```
