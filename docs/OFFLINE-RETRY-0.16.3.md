# 0.16.3 / build 53：全部重試

「我的 → 離線下載」總覽和單部劇頁面新增「全部重試（N 集）」。總覽涵蓋目前片庫的失敗集數，劇內按鈕只處理該劇；沒有可重試項目時隱藏。

批次操作會重新核對當下狀態，只接受下載失敗且來源格式受支援的項目。已完成、排隊中、下載中、手動取消及匯入影片不受影響。重試項目一次保存到佇列尾端，沿用既有逐集下載與取源恢復，不增加同時下載數。重複點擊不會重複加入同一筆已排隊項目。

## 驗證

- `swift test --filter OfflineDownloadsTests`：17 項通過。新增案例涵蓋跨劇／scope 選擇、重複 key、未知 key、已完成影片與進度保留、取消項目排除、現有下載順序、批次持久化及重複提交。
- iPhone Duo 模擬器使用獨立 QA App，載入正式下載 View、Model 與佇列，下載 provider 使用可控制的測試資料。初始共 4 集失敗；在甲劇按「全部重試（2 集）」後甲劇成為 3／3，乙劇仍為 0／2；返回總覽按「全部重試（2 集）」後乙劇成為 2／2，按鈕消失。直接讀回片庫確認 5 筆皆完成。
- 收合螢幕驗證單劇操作，展開螢幕驗證總覽布局及操作。測試後關閉模擬器。
- 模擬器 Debug 與實機 Release 建置通過。本版未修改取源或影片處理，未重跑上一版的整部真實影片下載；本次模擬器驗證僅用於批次重試操作。

本機證據：`build/offline-retry-all-0.16.3/`；實機建置與安裝證據：`build/phone-0.16.3/`。QA App 使用獨立 bundle 和片庫，不會操作使用者的離線影片。
