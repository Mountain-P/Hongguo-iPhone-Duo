# 選劇資料與介面

查閱日期：2026-11-07。當前版本為 0.8.2／build 21，使用「首頁／試看／劇場／我的」原生分頁。保留公開作品 metadata、完整直式海報、同頁連續首集試看、本機推薦、試看接續正式播放、繁簡補查與題材篩選。本版調整局部排除、同集進度容差、有效試看標記與控制顯示，保留試看滿版布局與底部安全距離；一鍵「接著看」、內建畫質偏好與有界海報載入持續保留。播放與診斷另見 [NATIVE-PLAYBACK.md](NATIVE-PLAYBACK.md)，帳號操作見 [ACCOUNT.md](ACCOUNT.md)，實際驗證集中於 [TESTING.md](TESTING.md)。

劇集詳情提供「更新劇集」入口。同一來源更新失敗時，保留上次成功的分集、定位與播放入口，並明確顯示正在使用上次資料；切換來源後則隱藏舊來源的可播資料，晚回覆不能回填。首頁與劇場遇到完整重複或空頁時，若來源仍表示有下一頁，就保留手動繼續載入，最多 100 頁；回到頁面不把成功空頁重設為第一頁，錯誤頁碼也不推進游標。

## 資料入口

| 入口 | 資料依據 | 顯示範圍 |
| --- | --- | --- |
| 推薦（劇場） | 官網 `/category/{contentType}` | 真人劇、漫劇、AI 劇的公開熱門目錄，並非個人化推薦 |
| 首頁本機排序 | 目前公開候選與目前片庫的收藏／合格保存位置 | 僅以真實共同題材調整新增頁；不使用官方個人化 API |
| 搜尋 | 目前目錄服務的搜尋結果 | 原關鍵字優先；只依來源明確提供的標籤篩選已載入結果題材，不推測內容類型 |
| 試看 | 目前目錄的 `CatalogService.home` 與該劇詳情 | 依真實候選、本機偏好與當前片庫題材線索排序，逐部試播可用的第 1 集，不使用官方個人化推薦 feed |
| 排行榜 | 官網 `/rank/{route}` | 總榜、真人劇、漫劇、AI 劇；名次、熱度及評分只顯示來源提供的文字 |
| 新劇 | App 公開目錄 metadata 的 `online_time=days_7`、`sort=online_time` | 真人劇、AI 劇分開取得的近期上新；不是未來排期或全站跨類時間排序 |
| 分類 | 官網 `/category/{contentType}/{genre}` | 題材選項讀取該內容類型的 `selectorList`，不以搜尋關鍵字冒充分類 |
| 藝人 | 劇集 `celebrities` 與官網 `/character/{id}` | 姓名、頭像、角色、公開簡介和當次頁面提供的參演作品；不稱完整生涯 |
| 相似推薦 | 劇集詳情 `recommendationGroups.related_list` | 官網對該劇提供的相似片單，排除本劇並去重，不混入 `hot_list` |

推薦與分類從官網的結構化 SSR JSON 讀取。排行榜有分段傳送的 JSON literal，必須依 route 與 content key 讀取；不執行網頁提供的 JavaScript。原始官網頁面及臨時實網快照留在 `build/catalog-research-0.3.0/`，不隨程式或來源包發行。

舊專案的 `sort_type=2` 在本輪檢查中，對新分類路徑回傳 404，對舊 `/category` 入口則重導後回到 `sort_type=1`。因此沒有將該入口標成最新排序。公開目錄也沒有可可靠使用的發布時間；不把建立時間、數字狀態或作品編號推算成上架日。

## 互動

- 首頁與劇場的搜尋維持明確入口，瀏覽及切換篩選只請求劇集 metadata。搜尋從詳情返回時保留原查詢與分頁，載入下一頁失敗可重試該頁；切換來源或查詢則隔離舊請求。
- 劇場題材篩選先在面板選擇，套用後重新載入；切換模式或題材時隔離舊請求與分頁，避免不同條件的海報混在一起。
- 劇場題材使用服務端真實分類。沒有將當頁的完結／更新中篩選包裝成全片庫查詢；搜尋結果的本機題材篩選另見下節。
- 首頁與劇場海報沿用等比完整顯示與自適應網格，點海報先看詳情，明確開始觀看才取影片來源。一般續播使用保存位置；「接著看」遇已完成集時依集數接續下一個可用集，明確重播已完成的同集則從零開始。
- 詳情頁的演員卡可進入藝人作品頁；評分、熱度、收藏／按讚數與發布日期只在來源提供時顯示。發布日採 `first_visible_time`，不使用作品 `create_time` 替代。
- 演員與相似片單沿用同一次劇集詳情回應；選用 metadata 缺失或格式變更時不阻止已正常的分集與播放入口。
- 使用選用橋接時，僅顯示橋接協定已支援的目錄與搜尋能力。

## 從最近觀看一鍵續播

首頁在劇場式主網格上方顯示目前片庫最近最多 5 部，採約 260×120 pt 的緊湊橫向卡：左側完整小海報，右側片名、上次集數／進度與至少 44 pt 的明確續播按鈕。點海報仍進詳情，主網格規格不變。「我的」歷史卡也提供「接著看」，編輯多選時保留原選取操作，不把選卡當成播放。

按鈕才載入最新詳情、核對最新紀錄並建立播放器；未完成集從保存位置繼續，完成集略過未開放集接下一個可用集，末集則從零重播。準備期間紀錄被清除時，續播會停止而非默默播放第一集。每個 parent 只管理一個 launcher／presentation，首頁一般點播與續播共用同一入口。

載入同時檢查 owner、來源 revision、scene、parent 可見性與請求世代；取消或切換 context 的舊回覆不能呈現。進度 handler 在最後核對後綁原片庫，避免換帳號後回寫另一個帳號；細節見 [ACCOUNT.md](ACCOUNT.md)。

## 畫質與海報載入

內建播放提供「自動（最佳可用）」與「省流量」偏好，依來源當次提供的可用影片模型選擇；不保證固定解析度，不是自適應串流或播放中即時切流。畫質設定沿用內建取源，不把帳號憑據交給影片 CDN。

海報依顯示尺寸解碼縮圖，使用有界的記憶體快取、有限並行與相同尺寸請求共用；取消一個讀取者不影響其他仍需要同圖的讀取者。海報不使用帳號 Cookie 或另建磁碟圖片快取。這些是已實作與合成測試覆蓋的行為，不等於已量出真機記憶體、流量或耗電改善幅度。

## 搜尋與簡繁容錯

搜尋先正規化 Unicode 與前後空白，再以原關鍵字查目前選定的來源。只有第一頁為空、且來源明確沒有更多頁時，才依本機字形轉換補查一次簡體或繁體；有結果、有更多頁、來源錯誤或工作已取消時，都不改詞重查。補查仍使用同一個服務，不更換來源，也不併發搜尋多種字形。

若替代字形找到結果，畫面會顯示實際補查詞，後續分頁沿用該詞；搜尋欄與歷史保留原關鍵字。從詳情返回仍保留搜尋與已載入分頁，換查詢或來源會使舊請求失效。

「題材篩選」的選項只取自已載入作品的來源標籤，並標出各題材數量。它是本機結果篩選，不是全站題材查詢，也不把共同的數字欄位或片名猜成真人／漫劇／AI 類型。沒有標籤的作品仍會留在「全部題材」；某題材暫時沒有顯示結果時，可切回全部，來源還有下一頁也仍可手動載入。

清空搜尋欄可回到「最近搜尋」，逐筆刪除紀錄或按「全部清除」。刪除搜尋歷史不會變動收藏、觀看歷史或續播位置。

## 片庫內找劇與整理

「我的」搜尋只比對目前選定片庫中已保存的劇名、簡介、題材與歷史分集名稱，容忍簡繁、全半形及大小寫差異，不向來源另發搜尋。收藏可按片庫順序或名稱正／反序排列；觀看歷史可按最近／最早觀看、名稱或本集進度排列，並保留「全部／本集未完／本集看完」篩選。「本集看完」不代表整部劇已看完。

按「編輯」進入多選；「全選顯示結果」只選符合目前搜尋與篩選的作品。確認面板顯示片庫與選取數量，取消或切換片庫不會把操作套到另一個帳號：

- 移除觀看紀錄只影響目前片庫在本機的紀錄，不刪除官方觀看歷史，收藏仍保留。
- 取消本機收藏只更改本機片庫；取消帳號收藏會加入待同步操作，觀看紀錄仍保留，來源尚未確認時不當作同步成功。

搜尋、篩選及排序本身不改寫片庫或同步佇列，批次操作才在明確確認後提交。

## 快速選集

詳情頁按來源提供的實際集數排序，每 30 集分組，例如 1–30、31–60、91–102；最後一組不補出不存在的集數。選「集數範圍」可切換當前網格，不必展開整部長劇。

- 在「輸入集數」填數字，按「跳至」會切到對應分組、定位並描邊該集。輸入無效或來源沒有該集時，顯示提示。
- 有同一部劇的有效紀錄時，「上次第 n 集」可定位原觀看分集；以實際分集 ID 核對，不把另一部劇的相同集號當成續看位置。
- 定位與分組切換都不會播放或寫入觀看進度。點可用分集才沿用原播放／續播流程；定位到未開放集時顯示提示，分集保持停用。

控制列在窄畫面或大字級可換成直式排列，分集按鈕依文字大小調整。這些布局調整與完整 VoiceOver、真機大字級驗收分開記錄。

## 逐部第一集試看

使用者選取「試看」分頁後才會載入片單；首頁及劇場不會因滑動海報而自動播放。試看採同一個垂直分頁 ScrollView，每部劇佔一個完整可用畫面，拖曳時卡片跟手移動，前後卡片與海報實際位於相鄰頁。滑動及慣性減速期間暫停播放，只有停穩且與畫面對齊的當頁取得啟播資格。已載入影格在拖曳期間保留，尚未準備的相鄰卡片顯示海報，不另跳播放器頁。

0.8.1 將試看分頁延伸至容器底部，原生分頁列背景改為透明；每頁高度與實際 viewport 一致，影片與 placeholder 海報等比填滿、裁切於卡片邊界，保留穩定劇集 ID。HUD、準備中的取消操作與錯誤提示另保留底部安全距離，不藉由縮短整頁影片來避讓；一般海報網格仍完整顯示封面。各姿態與手機的實際結果見 [TESTING.md](TESTING.md)。

首次選中的劇從第 1 集零秒試播；第 1 集缺失或未開放時顯示重試／換劇選項，不以其他集代替。單集播畢暫停，再按播放會回到開頭重播，沒有自動連播整劇或自動換劇。試看不寫觀看歷史或原有續播位置。卡片提供兩個明確入口：

- **追這部**：先擷取當下分集、秒數與時長，停止試看，再核對最新詳情與目前正式紀錄。若已有不同正式進度，顯示「接續原進度／從試看位置看」選擇；確認後才進入正式播放器並沿用正常進度保存。試看擷取本身不寫入片庫，已失效或未開放的分集不默默換成其他集。
- **點片名看詳情**：在同一個 NavigationStack 進入該劇詳情與完整選集，仍由使用者明確開始播放。

返回保留原卡片和捲動位置，等待手動「繼續試看」。準備或選擇位置時可取消；切換帳號、來源或離開後，舊準備結果不能啟動播放器。

卡片上的愛心可直接加入或取消收藏，不必先進詳情。收藏沿用目前選定的本機／帳號片庫及待同步流程，與本機試看標記分開。

點影片空白處顯示／隱藏控制列，不直接暫停或播放；使用中央播放／暫停按鈕控制影片。右上重複播放按鈕已移除。同頁試看長按僅提供暫時 2 倍速，放開恢復；上下拖曳交給原生分頁，不做鎖速手勢。一般全螢幕播放器原有的長按後上／下滑鎖定與解鎖維持獨立。

片單按劇集 ID 去重，僅對新加入的候選套用下節的本機排序，以穩定 ID 保持捲動錨點。啟播資格綁定可見卡、停穩狀態、分頁／場景狀態與請求世代，A→B→A 的舊回覆也不能回填。切換來源、離開分頁、背景化或開啟詳情會停止舊工作。片單、已準備卡片快取與總分頁有上限，近片單尾端才續讀有限的重複／空頁，避免背景無限請求。這是目前目錄的試看入口，不包含官方個人化排序或假造的喜歡／播放數。

## 本機推薦排序

首頁與試看從目前目錄已提供的候選中排序，不額外替每張卡片抓取詳情。興趣線索只取自目前所選本機／帳號片庫的來源題材標籤：收藏是較強訊號；最近 60 天內、至少保存到 30 秒且到達半集的位置是較弱訊號。保存位置可能受拖曳影響，因此不宣稱是真實停留時間、看完或喜歡。自動試看曝光與「已試看」標記不加入正向興趣。

理由只在候選與已知作品有實際共同題材時顯示，例如「因你收藏《…》· 懸疑」或「你最近看的《…》也有『甜寵』」。不從片名猜題材，不以泛用的「劇情／短劇」標籤作喜好，也不宣稱同主演推薦。沒有有效線索、候選未匹配或片庫範圍不符時，保留來源順序，不編造理由。

排序保留探索位置：每四個位置優先留一個給尚未匹配的候選，同題材連續兩張後可交錯其他已匹配題材；同分以原來源順序決定。每次最多參考 200 部收藏、200 筆歷史、64 個題材，每劇最多 8 個題材、每題材最多 6 個證據；單批候選最多 500 部。這是有界的本機排序，不代表全站完整推薦。

興趣快照與目前帳號／本機 owner、播放來源綁定，不跨片庫使用，不寫回官方推薦 API。首頁在新頁回應到達時再讀取已還原的當前片庫，僅排序新加入的海報；試看興趣更新只影響之後的新批候選與理由。現有片單與正在看的卡片不因收藏或逐秒進度變動而重排，切換片庫則清除舊範圍的理由與工作。

## 本機推薦偏好

在試看卡片的選項中開啟「推薦偏好」，或從「我的 → 設定 → 推薦偏好」進入：

| 選項 | 行為 | 恢復方式 |
| --- | --- | --- |
| 真人／漫劇／AI 短劇 | 使用內建目錄對應類型的真實片單 | 隨時切換類型；自訂服務的類型由服務決定，這個選項停用 |
| 略過已試看的劇 | 目前卡片前景有效播放累計 10 秒才標記；短片採片長九成、最低 1 秒，當前卡片保留 | 關閉略過，或按「重新顯示試看過的劇」清除標記 |
| 不感興趣 | 就地移除所選作品並移至相鄰一部，保留其他片單與分頁 | 按「恢復這些推薦」清除隱藏清單 |

偏好保存在這部 iPhone，不提交到官方帳號，不修改官方推薦，也不跟隨帳號片庫同步。暫停、緩衝、背景及滑動期間不累計有效試看時間；倍速與跳進度不代替實際播放時間，未保留的卡片不跨重建保存累計。「已試看」不等於已看完一集，更不是正式觀看進度；清除標記不會清除歷史、收藏或續播位置。兩份記憶清單各最多保存 1,000 個劇集 ID。

單筆不感興趣不重抓第一頁；載入中的舊頁及詳情回應也不能復活隱藏作品。類型、略過或恢復選項改變後仍會重新建立試看片單，舊條件的請求不能混入新結果；通過篩選的新候選可套用本機題材排序，沒有有效線索時保留來源順序。遇到整頁皆被排除或重複的結果，只在有上限的範圍繼續找劇；沒有符合項目時可調整偏好、重新載入或明確按「繼續找劇」，不會無限保持載入狀態。

## 從選劇到正式播放

詳情點播後沿用既有續播位置；停在已播完的分集再按播放，會先回到開頭。手動倍速與自動下一集開關保存在本機，試看仍禁用跨集連播。正式內建播放只在接近片尾、當集緩衝足夠、自動下一集開啟且網路／電力政策允許時，受限準備下一個可用集的首段；暫停、離頁、背景化或關閉自動下一集會取消，不另建播放器或預下載整集。

「我的 → 設定 → 播放診斷」可查看最近 80 次已結束的本機測量，包括首幀等待（TTFF）、播放中等待與重試；另顯示目前記憶體、溫度和低耗電狀態，不逐次保存資源快照。原片重播不計入首幀中位數；MetricKit 系統日報另列整個 App 的統計，可能包含不同版本，不是單次影片測量。診斷不記錄片名、內容 ID、網址或帳號，不外傳；它提供量測工具，不代表已證實效能或耗電改善。

## 版本與驗證

0.8.2／build 21 修正不感興趣的局部排除、相同續播意圖的兩秒容差、HUD 隱藏及有效試看計時；0.8.1 的試看滿版布局持續保留。測試統計由 [TESTING-CORE.md](TESTING-CORE.md) 記錄，GUI、實網、手機與效能結果另依 [TESTING.md](TESTING.md)。本文件不將實作、合成測試或建置當成裝置操作驗收。

歷史 0.7.0 完整測試為 Core 294 項／38 個 suites（293 通過、1 略過）及 AppSupport 50 項／5 個 suites（全數通過），合計 344 登錄、343 通過、1 略過，記錄於 `build/core-0.7.0-validated-tests.log`；兩平台 build 18 已通過。0.6.x 與 0.5.0 的對應結果仍保留於各版驗證紀錄。

歷史 0.4.4 Core 回歸為 199 項、23 個 suites，198 項通過、1 項可選快照略過；當時同頁 feed 通過完整模擬器建置。這些結果保留於對應版本驗證紀錄，不當作 0.5.0 新增偏好、收藏及選集操作，或 0.6.0 後續功能的驗收。

歷史 0.4.3 的第 1 集試播、切劇、暫停／倍速與正確 96 集詳情導航，以及四秒合成三集影片的兩次自動銜接，仍依版本記錄保存；這些不直接當作 0.4.4 新同頁介面的驗收。
