# 0.17.2 / build 59：相容畫質選擇

以 0.17.1 / build 58 為基線。原本自動畫質先按 codec 排序，再按解析度排序；同一集若同時提供 H.264 720p、HEVC 1080p，可選到 720p。新版本在自動串流優先選可解碼的最高解析度，同解析度仍優先 H.264。ByteVC2 不和可直接播放的來源混作備援；只有 ByteVC2 的模型仍交由原有流程處理。本次沒有改網路請求、身分、權限、下載的畫質門檻或省流量模式。

Node 與 iPhone 本機 JavaScript 選擇器同步；保留每集既有驗證，且只有同一 rendition 的鏡像 URL 會沿用該 rendition 的資訊。沒有把另一集、另一種編碼的 URL 當作鏡像。固定資料覆蓋高畫質 HEVC、同畫質 H.264 優先、排除 ByteVC2、連續兩集各自的來源、原有省流量與下載政策。這些測試不代表實網取源、實機自動續播或家中 bridge 已驗收。
