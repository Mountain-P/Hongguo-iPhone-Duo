# 後續改善

0.4.3 已優先處理倍速／暫停／換集狀態、首集滑動試看、續播與搜尋返回，以及結果未明的帳號寫入重試。以下是程式檢查發現的下一輪目標，尚未宣稱已完成或量測出效能改善。

1. **大型片庫儲存更順暢**：目前觀看進度與每筆作品資料補齊都可能在主執行緒完整編碼、備份和寫入片庫。改為依片庫序列處理、合併寫入，並驗證離開／背景時的最後進度及跨帳號順序。
2. **海報補齊的公平性與快取上限**：前 50 筆持續失敗可能阻擋後面的作品；詳情快取也需要容量／時效上限。以可見項優先、失敗退避和輪替批次處理，使用大型合成片庫驗證。
3. **重疊影片請求去重**：AVFoundation 同時要求相同區塊時，快取尚未完成可能產生重複下載。共用進行中的下載，並保持每個讀取者的取消互不影響。
4. **大字級與完整輔助使用**：讓海報文字隨 Dynamic Type 縮放，調整大字級欄數，逐頁檢查 VoiceOver、倍速提示及試看換劇的焦點。

每項都應以獨立提交記錄實作與對應驗證；模擬器、核心測試及真機證據分開保存。當前結果見 [TESTING.md](TESTING.md)。
