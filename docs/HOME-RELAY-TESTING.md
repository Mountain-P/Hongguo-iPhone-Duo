## 實測發現並修正

1. 舊下載器已解密檔案仍殘留 `senc/saiz/saio`，手機嚴格離線檢查拒絕該檔。
   中繼改為解析真正的 box／clear sample entries，僅在輸出時把殘留輔助 box 改成同長度填充，
   不改原檔、位元組位置或樣本。原始與整理後的完整影音解碼 SHA256 相同。
   真正的加密 sample entry 仍被拒絕；不以搜尋字串方式修改媒體樣本。
2. 模擬器測試 App 必須用 Xcode 的正常 simulator signing，才能測試真實 Keychain；
   沒有把正式憑證儲存改成明文。獨立 QA 套件與私有設定不會取代手機資料。
3. 同樣在傳輸中斷開、令中繼 8 秒無法連線，原版傳輸記錄約 21.46 秒停滯及一次播放器重載。
   加上限定中繼使用的 Range 接續與有限延遲重試後，記錄約 7.68 秒停滯、零重載，並完整播完。
   接續核對同一 URL、ETag、總長度及 offset；日誌顯示從已交付位元組接續。
   這是單次故障注入的對照結果，不代表所有網路環境都會有相同改善幅度。
4. 中繼回傳不完整或不合格式的檔案仍拒絕保存，但保留手動重試能力，讓伺服器修正後可再下載。

## 邊界與證據

- 102 個離線解碼畫面不是 34 集全部逐秒播完；完整連播、冷取源與故障恢復測試另有完整播放紀錄。
- 離線測試使用本機 file URL，下載 provider 設為一旦呼叫即失敗；未停用 Mac 全系統網路。
- 自檢每 15 分鐘檢查真實取源和 MP4 開頭；它不等於整集解碼，也不會自行改寫未知的新協定。
- 家中網路的模擬器結果不代表東京、漫遊或行動網路的實際速度；家庭上傳與跨境路由仍需實測。
- 帳號功能保留原路徑，測到本機收藏跨模式保留；沒有重新登入使用者帳號或宣稱遠端帳號同步已驗證。
- 原任務沒有海報資料的片庫項目使用預設圖與原劇名。
- 私有影片、口令、家中設定與原始網路日誌不發布到 Git。可重現命令見 [HOME-RELAY.md](HOME-RELAY.md)。
  本機 ignored `build/relay-qa/` 與 `build/home-relay-qa-*/` 保留測試輸出及來源 SHA256 清單。
- 最後核對 126 個 App／Core 原始檔與模擬器測試快照一致；49 個部署後端檔與本地雜湊一致。
